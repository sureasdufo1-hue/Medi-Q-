# MediQ 합성 검사 화면 설명 가이드

**Document ID:** `KB-DEMO-MEDIQ-001`  
**Version:** `1.0.0`  
**Classification:** `SYNTHETIC_DEMO`  
**Clinical Approval:** `NONE`  
**Use:** UI field explanation and clinician-question preparation only

## CHUNK-DEMO-001 — 합성 데이터 표시

`SYNTHETIC` 표시는 화면의 검사값과 환자정보가 실제 진료기록이 아니라 기능 시연을 위해 만든 자료라는 뜻이다. 이 자료를 진료, 진단 또는 치료 결정에 사용하면 안 된다.

## CHUNK-DEMO-002 — 값과 단위

검사결과 화면은 검사명, 합성 결과값과 단위를 서로 구분해 표시한다. 같은 이름의 검사라도 검사법이나 단위가 다를 수 있으므로 MediQ는 서로 다른 단위의 값을 임의로 합치거나 변환하지 않는다.

## CHUNK-DEMO-003 — 제공기관 참고범위

`제공기관 참고범위`는 합성 제공자가 함께 제공한 표시정보다. MediQ가 만든 정상·비정상 판정이 아니다. 실제 결과의 의미는 검사법, 단위와 개인 상황에 따라 달라질 수 있으므로 담당 의료진에게 확인해야 한다.

## CHUNK-DEMO-004 — 원문 판정

`제공기관 원문 판정`은 합성 Fixture에 들어 있는 원문 표시를 그대로 보여주는 항목이다. MediQ는 이 문구를 새로 계산하거나 질병·면역 상태로 확대 해석하지 않는다.

## CHUNK-DEMO-005 — 의료진에게 준비할 질문

환자는 담당 의료진에게 검사법과 단위가 무엇인지, 이전 검사와 직접 비교할 수 있는지, 추가로 확인할 자료가 있는지 질문할 수 있다. MediQ의 질문 제안은 상담 준비용이며 치료나 투약 변경을 지시하지 않는다.

## CHUNK-DEMO-006 — 자료의 한계

기록이 화면에 없다고 해서 검사를 받지 않았다는 뜻은 아니다. 기관 미연결, 제공 지연, 동의 필요 또는 제공하지 않는 항목일 수 있다. MediQ는 누락된 값을 추정하지 않는다.

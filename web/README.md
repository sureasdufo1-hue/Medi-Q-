# MediQ Web

Patient consent 흐름, Hospital B 요청 흐름, 승인된 Cloud Viewer와 DICOM Download를 구현한다.

구현 기준은 [`../docs/P0-WEB-UI-UX-SPEC.md`](../docs/P0-WEB-UI-UX-SPEC.md)이며, 기술 기준은 [`../docs/TECH-STACK-DECISION.md`](../docs/TECH-STACK-DECISION.md)다.

현재 상태는 문서화 단계이며 실행 가능한 Frontend는 아직 없다.
